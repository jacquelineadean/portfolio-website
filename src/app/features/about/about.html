About

I work on the systems that are hard to change.

Most of my work is on large legacy platforms — pulling them apart into modular, cloud-native services without interrupting the business running on top of them.

That work is as much sequencing as it is engineering: which seam to cut first, what has to keep running while you cut it, and how to prove the new path is correct before the old one is retired. I'm drawn to the problems where system boundaries are blurred, requirements move mid-flight, and every decision is a tradeoff. Backend service design, API development, data modeling, frontend integration — I work across the stack, with an emphasis on maintainability, performance, and operational clarity.

I value clear ownership, thoughtful abstractions, and engineering decisions that balance correctness with pragmatism.

Principles

The best code isn't clever — it's confident, extensible, and easy to hand off.
